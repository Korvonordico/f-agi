# F-AGI

*wholeness*

Under construction, coming soon.

F-AGI will bring together a set of tools around an AI agent and use, each time, only the ones a job needs. Each tool also works on its own.

## Modules already public

- [Token Tranche](https://github.com/Korvonordico/quotient-claude-tokens), today still called Quotient - *prudence & measure*: know what a Claude Code or Hermes job will cost before it starts, and split big jobs into installments that fit your limits.
- [Psyche Map](https://github.com/Korvonordico/psyche-map) - *memory & knowledge*: a 3D map of your memories that grows while you chat with your AI.
- [Iris Insight](https://github.com/Korvonordico/iris-insight) - *sight & understanding*: lets an AI agent see the last seconds of a running program, in one cheap picture and a short log, to find what went wrong.

## Built with these tools

- [Shadow of Rome, PC port](https://github.com/Korvonordico/shadow-of-rome-recompiled) (experimental): its jobs were quoted and split by Quotient, and Iris Insight was tested on it.
